什么是 dsh

DeepSeek Harness 是 DeepSeek AI 开源的 agent harness，核心哲学是万物皆可插件：模型适配器、工具注册表、会话日志、权限模型，甚至 agent loop 本身都可以替换，没有需要打补丁的特权内核。运行时基于 Cordis 构建，共四种模式：

开发者预览版. 官方警告将有破坏性兼容变更，API 与插件契约都可能改动。

模式说明
Standard完整编码 agent：文件编辑、shell、文件与网页搜索、skills、规划、目标、子代理、工作流
CodeStandard 的全部能力，再加上 Code Mode SDK——把多步操作组合进一段 TypeScript 程序
Minimal双工具编码 agent（常驻 bash + str_replace_editor），用于模型基准评测
Creator运行时检查、内存内插件实验、组合新模式，用于编写自定义 agent 预设

常见问题

Awesome DeepSeek Harness 是什么？

这是独立的社区维护目录，收录 DeepSeek Harness（dsh）相关插件、工具、技能与学习资源，不是 DeepSeek 官方产品。

如何查找和安装 dsh 插件？

按名称或说明搜索，或选择一个分类。打开项目原始仓库，按照它的安装说明和兼容性要求操作。不同项目的安装方式可能不同。

星标数是实时的吗？

不是。各项目星标数是 README 中的快照；本目录自身的星标里程碑由 GitHub Actions 定期刷新。最新数量请查看原始仓库。

如何提交项目？

先阅读贡献指南，在对应分类添加匹配的中英文条目，再提交 Pull Request。项目需要与 dsh 相关、可安装可用，并有明确用途。

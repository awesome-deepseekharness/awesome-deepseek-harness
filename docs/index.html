What is dsh?

DeepSeek Harness (dsh) is DeepSeek AI's open-source agent harness. Its core philosophy: everything is a plugin — model adapter, tool registry, session log, permission model, even the agent loop itself are replaceable plugins, powered by Cordis.

⚠️ Developer Preview — compatibility-breaking changes are coming.
ModeDescription
StandardFull coding agent: file editing, shell, file & web search, skills, planning, goals, subagents, workflows
CodeAll of Standard, plus multi-step TypeScript programs via the Code Mode SDK
MinimalTwo-tool coding agent (bash + str_replace_editor) for benchmarking models
CreatorRuntime inspection, in-memory plugin experiments, and composing new modes

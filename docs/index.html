What is dsh?

DeepSeek Harness is DeepSeek AI’s open-source agent harness. Its core philosophy is that everything is a plugin: the model adapter, tool registry, session log, permission model and even the agent loop itself are replaceable, with no privileged core to patch. The runtime is built on Cordis. It ships in four modes:

Developer Preview. the official release warns that compatibility-breaking changes are coming, so APIs and plugin contracts may change.

ModeWhat it is
StandardFull coding agent: file editing, shell, file & web search, skills, planning, goals, subagents, workflows
CodeAll of Standard, plus tools exposed through the Code Mode SDK so one TypeScript program can chain multi-step operations
MinimalTwo-tool coding agent (persistent bash + str_replace_editor) for benchmarking models
CreatorRuntime inspection, in-memory plugin experiments, composing new modes — for authoring custom agent presets

Common questions

What is Awesome DeepSeek Harness?

An independent, community-maintained directory of plugins, tools, skills and learning resources for DeepSeek Harness (dsh). It is not an official DeepSeek product.

How do I find and install a dsh plugin?

Search by name or description, or choose a category. Open the original project repository and follow its installation instructions and compatibility requirements. Installation steps vary by project.

Are the star counts live?
